## 0. 先确认三件事（缺一件就交不了）

- [ ] 已经**注册并登录** ANS（邮箱 + 密码）
- [ ] 已经**报名**本赛事，且状态从 `PENDING` 变成 `APPROVED`（学院/年级/学号，人工审核）
- [ ] 你是**队长或管理员**（只有队长/管理员能提交）

## 1. 提交前 3 分钟自检

- [ ] Demo 能打开（评委视角，换浏览器 / 手机也行）：https://denghui1835.github.io/faststudy/
- [ ] Demo 是 HTTPS，**不需要登录**，链接里没有临时签名参数
- [ ] 仓库可访问：https://github.com/denghui1835/faststudy
- [ ] 记下当前 commit SHA（表单可填「Commit SHA」固定版本）

## 2. 页面操作顺序

1. 打开提交页 → 选「参赛队伍」→ 选「提交阶段：初赛 PRELIMINARY」
2. 选「提交的作品版本」（若还没有：先到 `/explore/agrihackathon/submit` 发布作品，等审核通过后回来选）
3. 填 **作品介绍**（下方第 3 节，≤4000 字）
4. 填 **仓库地址** + **ref 类型**（Commit SHA）+ **Demo 地址**
5. 材料项：原创声明、AI 模型使用说明（下方第 4、5 节）
6. 勾选「我已核对」→【正式提交】

> 支持截止前多次修改覆盖，**建议 16:00 前先交一版保底**，之后有时间再补。

## 3. 作品介绍（直接粘贴，≤4000 字）

见 [参赛说明.md](参赛说明.md) 第二节「作品介绍」。若表单只收 200 字，用这个：

> FastStudy 是一个按「距考几天」切换策略的期末冲刺小程序。填上科目、天数、目标分和基础，它先把考点按「考频 ÷ 你的掌握度」排出性价比，再生成今日任务；做题时不会直接给答案，而是先用三段引导让你自己想，判错后才讲「考什么、错在哪、记住哪一句」，错题自动进急救本，答对即出本。14 天以上系统重建，4–13 天定点爆破，3 天内进保命模式，只做高频与中低难度题。

## 4. 原创声明（直接粘贴）

> 本作品的产品设计、代码与全部题库内容均为本次比赛期间（2026-11-20 18:00 之后）由参赛者本人原创完成，仓库首个 commit 即位于初赛窗口内，可作为时序证据。作品未使用任何第三方受版权保护的题库，84 道题均为原创编写；未使用需授权的商业 SDK、字体或图标库；依赖均为 MIT/Apache 开源许可（React、Vite、TypeScript）。

## 5. AI 模型使用说明（直接粘贴）

> 产品构思与需求梳理：使用 DeepSeek 辅助梳理「按倒计时切换策略」的产品结构与文案。
> 代码编写：使用 DeepSeek 驱动的 AI 编码助手生成组件骨架与样式，由本人审定、修改、联调。
> 题库内容：在 AI 辅助下逐题编写与校对，知识点人工复核。
> 产品运行时：用户可自填 OpenAI 兼容接口（如 DeepSeek）生成讲解；未配置时使用本地规则引擎，完全离线。Key 仅存浏览器 localStorage。
> 未使用 AI 生成图片，视觉为 CSS 自绘 + 系统 emoji。
