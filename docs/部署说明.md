# 部署到 GitHub Pages（gh-pages 分支）

> 之所以走分支部署而不是 Actions：当前的 GitHub token 没有 `workflow` scope，
> 推送 `.github/workflows/*` 会被拒绝。分支部署同样能拿到 HTTPS 域名。

```powershell
# 1) 构建
npm run build

# 2) 把 dist 推到 gh-pages 分支
$tmp = Join-Path $env:TEMP "fs-pages"
if (Test-Path $tmp) { Remove-Item -Recurse -Force $tmp }
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
Copy-Item dist\* $tmp -Recurse -Force
Push-Location $tmp
git init -b gh-pages -q
git add -A
git commit -q -m "deploy: $(Get-Date -Format yyyy-MM-dd-HHmm)"
git remote add origin https://github.com/Denghui1835/faststudy.git
git push -f origin gh-pages
Pop-Location
```

- 站点：https://denghui1835.github.io/faststudy/
- `vite.config.ts` 里 `base: './'`，所以子路径部署与任意静态托管都能直接用
- 首次启用：仓库 Settings → Pages → Source 选 `gh-pages` / `/ (root)`
