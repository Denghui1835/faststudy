## ② 简介（≤200 字，直接复制）

```
FastStudy 是一个按「距考几天」切换策略的期末冲刺小程序。填上科目、天数、目标分和基础，它先把考点按「考频 ÷ 你的掌握度」排出性价比，再生成今日任务；做题时不会直接给答案，而是先用三段引导让你自己想，判错后才讲「考什么、错在哪、记住哪一句」，错题自动进急救本，答对即出本。14 天以上系统重建，4–13 天定点爆破，3 天内进保命模式，只做高频与中低难度题。
```

## ⑥ 作品介绍（≤4000 字，直接复制）

```
【一句话】
FastStudy 是面向大学生的期末极限备考小程序：它把「还剩几天考试」做成策略输入，而不是背景装饰，用最短时间换尽可能多的分数。

【问题】
每学期最后两周，宿舍里都会出现同一句话：「这门课我一点没学，还有五天考试。」这时候市面上的工具都不合用——题库 App 有海量题却不告诉你先刷哪道，题海本身就是新的焦虑；通用 AI 学习助手会排一个「四周学习计划」，可你只剩五天；网课与教材假设你有时间，而时间恰恰是最缺的。真正的约束不是知识难，而是时间不够且不知道投在哪。

【核心机制一：倒计时驱动策略】
同一门课，剩 30 天、7 天、1 天，正确做法完全不同：
· ≥14 天「系统重建」：按章节铺满考点，允许开新章节，先搭框架再刷题；
· 4–13 天「定点爆破」：关掉全面覆盖的幻想，只打性价比最高的 3–5 个考点；
· ≤3 天「保命模式」：自动切档，题库过滤为「高频 + 中低难度」，放弃冷门章节，只保基础分与必考题型。
「保命模式」的想法很朴素：考前一夜最重要的不是学新的，而是别把已经会的丢掉。系统在这里主动劝退，是反直觉但真实有用的设计。

【核心机制二：性价比排序，可解释】
每个考点带两个属性：考频（高频/常考/了解）与你当前的掌握度（由做题记录实时计算）。排序公式为「性价比 = 考频权重 ÷ (1 − 掌握度)」，越靠前就是「老师爱考、你还不会」的题。首页直接把排序摊开，标注「未测 / 做过几题 / 正确率」，让用户看见系统为什么让他先学这个——把黑箱变成可解释。

【核心机制三：AI 引导式刷题，刻意延迟答案】
普通题库的行为是「答错→弹解析」。FastStudy 拆成三步：
1）不会就先讲讲思路：给出「考什么（含考频与建议花几分钟）→ 核心定义 → 怎么用排除法套定义」三段引导，但不给答案；
2）自己选：单选/判断点选即判，多选需确认；
3）判完才讲：展示「考什么 / 错在哪 / 记住这一句」，其中「记住这一句」是能直接背走的结论（如「顺序表=随机访问 O(1)，链表=只能顺序访问」）。
理由很直接：考场没有 AI 陪你。直接给答案会制造「我看懂了」的错觉，延迟答案才能逼出真正的回忆与判断。

【一组题之后的诊断】
默认 10 题、约 3 分钟一组，结束后生成诊断：本组正确率与平均用时；全组最弱考点，并按正确率分三种建议（<60% 停下补概念 / 60–85% 原地连刷 / >85% 抬难度）；若出现「5 秒内选错」的题会单独指出——那不是不会，是看题太快。

【其他已实现功能】
· 错题急救本：答错自动入本计数、按考点聚合，答对一次即自动出本（错题本必须是会缩短的，否则它只是第二个焦虑源）；
· 今日冲刺任务：过 N 个考点 / 刷 M 题 / 复盘 K 道错题，闭环可勾选；
· 学习看板：掌握度（按考频加权）、预估分、连续冲刺天数、总正确率、专注分钟；
· 自带模型：可填自己的 OpenAI 兼容接口生成讲解，不填则用本地规则引擎，完全离线；Key 只存浏览器 localStorage，不上传服务器。

【技术实现】
React 19 + TypeScript + Vite，纯静态、零后端，构建产物可直接丢在任意静态托管。策略引擎是纯函数 buildPlan(course, exam, progress, lifesaver)，输入倒计时/目标/基础/做题记录，输出模式、今日任务与题目队列，无副作用，可单测、可迁移、可被服务端复用。AI 层分两支：本地规则引擎（引导步骤 + 诊断文案）与可选 LLM 调用（/chat/completions，失败自动降级）。状态用 useReducer + localStorage，刷新不丢进度。题库 6 门课 82 道手写题，每题带三段式讲解与考频/难度标注。H5 优先（同学扫链接即用），题库与策略引擎与渲染解耦，已写好微信小程序迁移路径。

【差异化】
· 通用 AI 学习助手：假设你有充足时间 → FastStudy 假设你只剩几天；
· 题库 App：靠题量取胜 → FastStudy 靠排序与取舍；
· 讲解方式：直接给答案 → 先引导、再判、后讲解；
· 底层态度：什么都做 → 主动砍功能，只保分。
我们认为「主动放弃」是期末场景里最稀缺的产品能力：放弃冷门章节、放弃难题、放弃「学完」的执念——FastStudy 把这些放弃做成了默认行为。

【验证与路线图】
v0.1 全流程已跑通：创建计划 → 今日任务 → 引导刷题 → 判错讲解 → 错题复盘 → 看板，6 门课 82 题，无后端、离线可用，在线 Demo 可直接体验。
v0.2 计划接入课件/往年卷 PDF 自动抽取考点（把考频标注从手工变成数据驱动）；v0.3 限时模拟套卷 + 薄弱点报告；v0.4 室友组队冲刺；v1.0 微信小程序正式版（登录、云同步、分享）。

【一句话收尾】
我们不是想再做一个学习 App，而是想把「来不及了」这个处境认真对待一次。期末冲刺最需要的不是更多知识，是判断力：判断该放弃什么、先捡起什么、什么时候停下来把会的保住。FastStudy 把这份判断力做成了一套可执行的机制。
```
