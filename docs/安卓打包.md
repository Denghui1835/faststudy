# 安卓打包说明（Capacitor）

Web 端是纯静态 H5，用 [Capacitor](https://capacitorjs.com) 套一层原生壳就是安卓 App。
本仓库 `android/` 是完整的 Android Studio 工程，可直接打开。

## 环境

| 组件 | 本机版本 |
|---|---|
| JDK | 21（Android Studio 自带 JBR：`C:\Program Files\Android\Android Studio\jbr`） |
| Android SDK | `C:\Users\lenovo\AppData\Local\Android\Sdk`（platforms 36、build-tools 36.1.0） |
| Gradle | 8.14.3（wrapper 自动下载） |
| AGP | 8.13.0 |
| Capacitor | 8.6 |

## 构建

```powershell
# 1) 先出 Web 产物
npm run build

# 2) 同步到 Android 工程（会复制 dist → android/app/src/main/assets/public）
npx cap sync android

# 3) 打包 debug APK
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:ANDROID_HOME = "C:\Users\lenovo\AppData\Local\Android\Sdk"
cd android
.\gradlew.bat assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

> 从 Android Studio 打开 `android/` 目录，直接点 Run 也行。

## 本机遇到的两个坑

1. **项目路径含中文**（`D:\书山有路\...`）会让 AGP 直接报错：
   `Your project path contains non-ASCII characters`。
   解决：在 `android/gradle.properties` 里加 `android.overridePathCheck=true`。
2. **Gradle 走代理**：环境变量 `HTTP_PROXY` 对 Gradle 无效，必须写 `systemProp.http(s).proxyHost/Port` 到 `gradle.properties`（本机为 Clash `127.0.0.1:7897`）。

## 关于签名

仓库里的 APK 是 **debug 签名**（`CN=Android Debug`），适合演示与内测，安装时需允许「未知来源」。
要上应用商店需要自建 keystore 并配置 `signingConfigs`，命令：

```powershell
keytool -genkey -v -keystore faststudy-release.jks -alias faststudy -keyalg RSA -keysize 2048 -validity 10000
```

然后在 `android/app/build.gradle` 里加 `signingConfigs.release` 与 `buildTypes.release`，再 `assembleRelease`。
