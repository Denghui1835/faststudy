**200 字以内简介（可直接粘贴）**：

> FastStudy 是一个按「距考几天」切换策略的期末冲刺小程序。填上科目、天数、目标分和基础，它先把考点按「考频 ÷ 你的掌握度」排出性价比，再生成今日任务；做题时不会直接给答案，而是先用三段引导让你自己想，判错后才讲「考什么、错在哪、记住哪一句」，错题自动进急救本，答对即出本。14 天以上系统重建，4–13 天定点爆破，3 天内进保命模式，只做高频与中低难度题。

## 二、作品介绍（≤4000 字）

### 1. 我们盯上的那个瞬间

每学期最后两周，宿舍里会出现同一句话：「这门课我一点没学，还有五天考试。」

这时候市面上的工具都不太合用：

- **题库 App** 有海量题，但不告诉你先刷哪一道，题海本身就是新的焦虑；
- **通用 AI 学习助手** 会热情地给你排一个「四周学习计划」——可你只剩五天；
- **网课 / 教材** 假设你有时间，而这段时间正是最缺的东西。

真正的约束不是「知识难」，而是**时间不够，且不知道把有限时间投在哪**。所以 FastStudy 不解决「如何系统学完一门课」，只解决一个更硬的问题：

> **在还剩 N 天的情况下，怎么把这 N 天换成尽可能多的分数？**

产品的一句话是：平时欠的知识，期末一起还。

### 2. 核心机制一：让「倒计时」真的改变教学策略

同样是「数据结构」这门课，剩 30 天、剩 7 天、剩 1 天，正确的做法完全不同。我们把这件事做成了产品的第一性设计——**时间不是背景装饰，而是策略的输入变量**：

| 距考时间 | 模式 | 系统行为 |
|---|---|---|
| ≥ 14 天 | 系统重建 | 按章节铺满考点，允许开新章节，先搭框架再刷题 |
| 4 – 13 天 | 定点爆破 | 关掉「全面覆盖」的幻想，按性价比排序，只打最值钱的 3–5 个考点 |
| ≤ 3 天 | 保命模式 | 自动切档，并可从首页手动强开：题库过滤为「高频 + 中低难度」，放弃冷门章节，只保基础分与必考题型 |

「保命模式」这个功能的想法来源很朴素：**考前一夜最重要的不是学新的，而是别把已经会的丢掉。** 很多同学在最后 12 小时还在啃没考过的章节，结果把会的也搅乱了。系统在这里主动「劝退」，是一种反直觉但真实有用的设计。

### 3. 核心机制二：性价比排序，而不是按章节顺序

每个考点有两个属性：

- **考频**（高频 / 常考 / 了解）——由知识点在课程体系里的地位与历年考察习惯标注；
- **你的掌握度**——由你在这个考点上的做题记录实时计算（对/错次数）。

于是得到排序公式：

```
性价比 = 考频权重 ÷ (1 - 掌握度)
```

越靠前的，就是「老师爱考、你还不会」的题——提分空间最大。首页的「考点性价比排行」直接把这个排序摊开给用户看，并标出「未测 / 做过几题 / 正确率多少」，让用户知道系统为什么让他先做这个。

这件事的价值在于**把黑箱变成可解释**：用户不是被算法推着走，而是能看到「我为什么该先学这个」。

### 4. 核心机制三：AI 引导式刷题，先扶一把再让你走

普通题库的行为是「答错 → 弹解析」。我们把它拆成三步，并且**刻意延迟答案**：

1. **不会？先讲讲思路** —— 点「不会，先讲讲思路」，系统给三段引导：这题考哪个考点（以及它的考频意味着该花几分钟）、这个考点的核心定义、以及「怎么用排除法套定义」，但**不给答案**；
2. **你自己选** —— 选完立刻判对错（单选/判断点选即判，多选需确认）；
3. **判完才讲** —— 展示「考什么 / 错在哪 / 记住这一句」三段讲解，其中「记住这一句」是一句能直接背走的结论（例如「顺序表 = 随机访问 O(1)，链表 = 只能顺序访问」）。

理由很直接：**考场没有 AI 陪你。** 直接给答案会制造「我看懂了」的错觉，而延迟答案才能逼出真正的回忆与判断。这也是我们和「AI 讲解题库」最大的区别——AI 在这里不是答案机器，而是**苏格拉底式的提问者**。

一组题（默认 10 题，约 3 分钟）结束后，系统生成一份诊断：

- 本组正确率与平均用时；
- 全组最弱的考点，并区分三种情形给不同建议（正确率 < 60% 建议停下补概念；60–85% 建议原地连刷；> 85% 建议抬难度）；
- 如果出现「5 秒内选错」的题，会单独指出来：这不是不会，是看题太快。

### 5. 其他已实现功能

- **错题急救本**：答错自动入本并计数，按考点聚合展示；**答对一次即自动出本**——错题本必须是会缩短的，否则它只是第二个焦虑源。
- **今日冲刺任务**：把计划拆成「过 N 个考点 / 刷 M 题 / 复盘 K 道错题」三件事，闭环可勾选。
- **学习看板**：考点掌握度（按考频加权）、预估分、连续冲刺天数、总正确率、专注分钟。
- **自带模型**：可填入自己的大模型接口（OpenAI 兼容），把讲解换成在线大模型生成；不填也能用本地讲解引擎。Key 只存 localStorage，不上传服务器。

### 6. 技术实现

- **前端**：React 19 + TypeScript + Vite，纯静态，零后端依赖，`npm run build` 出来就是一份可以丢在任何静态托管上的文件。
- **策略引擎**（`src/lib/plan.ts`）：纯函数 `buildPlan(course, exam, progress, lifesaver)`，输入倒计时/目标分/基础/做题记录，输出模式、今日任务、题目队列。无副作用，因此可单测、可迁移到小程序、可被服务端复用。
- **AI 层**（`src/lib/ai.ts`）：本地规则引擎（引导步骤、诊断文案）+ 可选 LLM 调用（`/chat/completions`，OpenAI 兼容），失败自动降级到本地讲解，保证离线可用。
- **状态**：`useReducer` + localStorage，刷新不丢进度；无账号体系，符合「期末临时用一下」的使用场景。
- **题库**：6 门课、8+7+6+6+5+5 个考点、82 道手写题，每题均带三段式讲解与考频/难度标注。
- **多端**：H5 优先（同学扫链接就能用），题库、策略引擎与渲染解耦，微信小程序迁移路径见 `docs/小程序适配.md`。

### 7. 与同类产品的差异

| | 通用 AI 学习助手 | 题库 App | **FastStudy** |
|---|---|---|---|
| 前提 | 你有充足时间 | 你愿意刷题海 | **你只剩几天** |
| 计划 | 长期学习计划 | 无计划，自己挑 | **按倒计时自动换策略** |
| 讲解 | 直接给答案 | 静态解析 | **先引导、再判、后讲解** |
| 取舍 | 什么都做 | 题量取胜 | **主动砍功能：只保分** |

我们认为「主动放弃」是期末场景里最稀缺的产品能力：放弃冷门章节、放弃难题、放弃「学完」的执念。FastStudy 把这些放弃做成了默认行为。

### 8. 验证与下一步

- **已完成**：v0.1 全流程可跑通（创建计划 → 今日任务 → 引导刷题 → 判错讲解 → 错题复盘 → 看板），6 门课 82 题，无后端、离线可用；在线 Demo 可直接体验。
- **v0.2**：上传课件与往年卷（PDF），自动抽取考点与生成题目——把「考频标注」从手工变成数据驱动，这是我们最想补的一块，也直接对应「契合度」。
- **v0.3**：限时模拟套卷 + 薄弱点报告。
- **v0.4**：室友组队冲刺（进度同步、互相监督）。
- **v1.0**：微信小程序正式版（登录、云同步、裂变分享）。

### 9. 我们想说的话

我们不是想再做一个学习 App，而是想把「来不及了」这个处境认真对待一次。期末冲刺里最需要的不是更多知识，是**判断力**：判断该放弃什么、该先捡起什么、什么时候该停下来把会的保住。

FastStudy 把这份判断力做成了一套可执行的机制——这也是「人类与学习」这个方向里，我们认为最值得做的一小块。

## 四、AI 模型使用说明

按赛事要求如实披露：

| 环节 | 是否使用 AI | 具体说明 |
|---|---|---|
| 产品构思与需求梳理 | 是 | 使用大模型（DeepSeek）辅助梳理「按倒计时切换策略」的产品结构、页面清单与文案语气 |
| 代码编写 | 是 | 使用 AI 编码助手（DeepSeek 驱动的 Agent）生成组件骨架与样式，由本人审定、修改、联调 |
| 题库内容 | 是（辅助） | 题目由本人在 AI 辅助下逐题编写与校对，每题的「考什么 / 错在哪 / 记住这一句」均人工复核知识点正确性 |
| 产品运行时（用户侧） | 可选 | 用户可填入自己的大模型接口（OpenAI 兼容，如 DeepSeek），由模型生成个性化讲解；**未配置时使用本地规则引擎，完全离线**，不依赖任何在线模型 |
| 图片与视觉 | 否 | 无 AI 生成图片，视觉为 CSS 自绘 + 系统 emoji |

**运行时 AI 的调用方式**（若配置）：前端直接调用 `POST {baseURL}/chat/completions`，system prompt 约束为「120 字内、先说错因、再给一句结论」，请求体只含当前题目与用户所选选项，不含任何个人信息。Key 存于浏览器 localStorage。

## 五、评委关注点对照（便于快速查看）

**作品完成度**：全流程闭环可操作，6 门课 82 题，在线 Demo 直接可点，刷新不丢数据，无后端部署成本。

**创新程度**：把「距考天数」做成策略输入，而不是背景信息；「保命模式」主动压缩目标；「性价比排序」可解释地展示给用户；AI 引导式刷题刻意延迟答案。
