# 微信小程序适配说明

FastStudy v0.1 交付的是 **H5**（同学扫链接就能用，评委无需安装任何东西）。
但代码结构是按「一套逻辑、多端渲染」来写的，迁移到微信小程序只差渲染层。

## 为什么先做 H5

- 期末场景的传播路径是「群里发个链接」——H5 零门槛，小程序还需要审核；
- 比赛评审时间紧，H5 可以直接打开，不需要装开发者工具；
- 策略引擎与题库是纯 TS，与 DOM 无关，迁移时不用重写。

## 迁移映射

| H5 现状 | 小程序对应 |
|---|---|
| `src/data/*.ts`（题库 + 考点） | 原样复用；体量大可拆成 `utils/data/*.js` 或分包 |
| `src/lib/plan.ts`（策略引擎，纯函数） | 原样复用 |
| `src/lib/ai.ts`（引导 / 诊断） | 本地部分原样复用；LLM 调用从 `fetch` 换成 `wx.request`（小程序不允许直接跨域 fetch） |
| `src/store.tsx`（useReducer + localStorage） | `setData` + `wx.setStorageSync`；或迁到 Taro / uni-app 保留 React 写法 |
| `src/screens/*.tsx` | `pages/*` 的 WXML/WXSS 重写；`styles.css` 的设计变量可直接搬进 `app.wxss` |
| 底部 tabbar | `app.json` → `tabBar` |
| `?demo=1` 演示数据 | 换成小程序「体验模式」入口（首次进入给一份演示进度） |

## 页面清单（与 H5 一致）

```
pages/onboarding/   创建抢救计划（三步）
pages/sprint/       首页：倒计时、今日任务、性价比排行、保命模式
pages/quiz/         刷题：引导 → 作答 → 判错讲解 → 本组诊断
pages/mistakes/     错题急救本
pages/me/           看板与模型配置
```

## 需要注意的三点

1. **域名白名单**：若让用户填自己的模型接口，需要在小程序后台配置 request 合法域名；因此小程序版更适合内置一个后端代理，或默认走本地讲解引擎。
2. **体积**：题库 208 题约 135KB，可直接打包；题量上千后建议按课程分包 + 按需加载。
3. **登录与云同步**：小程序版才需要 `wx.login` + 云开发/自建服务；H5 版刻意不做账号，降低使用门槛。
